# 04: Código da prova na folha

**What to build:** a folha imprime uma faixa de quadradinhos com o código da prova (e a versão, quando houver). Ao ler, o app usa a prova do código e pergunta antes de trocar a prova ativa. Avisa se a prova não está no aparelho. Folha sem código legível (inclusive as antigas) usa a prova ativa.

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] Seam Leitura: código lido com rotação, perspectiva, ruído e cópia; código danificado vira "sem código"; folha antiga sem faixa
- [ ] Seam App: foto da folha de outra prova pergunta "Esta folha é da prova X. Corrigir nela?" e corrige na certa
- [ ] Seam App: código de prova que não está no aparelho mostra aviso
